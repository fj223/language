# 课程播放页重构 - 页面设计说明（Desktop-first）

## Global Styles（全局）
- 设计基调：学习场景，低干扰。
- 背景色：#0B1220（深色）或 #FFFFFF（浅色），二选一并全站一致。
- 主色（Accent）：#3B82F6；成功：#22C55E；危险：#EF4444；文本主色：#0F172A / #E5E7EB（随主题）。
- 字体：系统字体栈；字号：12/14/16/20/24；行高 1.4–1.6。
- 按钮：主按钮（实心）、次按钮（描边）、文字按钮；Hover 提升亮度 6–10%。
- 卡片：圆角 12px；阴影轻量；边框 1px（#E2E8F0 / #1F2937）。

## Page: 课程播放页

### 1) Meta Information
- Title：{课程标题} - 播放
- Description：观看课程资源并记录学习进度。
- Open Graph：
  - og:title = {课程标题}
  - og:description = {课程简介（截断）}
  - og:type = website

### 2) Layout
- 桌面端（>= 1024px）：左右两栏布局（CSS Grid）。
  - 左侧：播放器与资源区域（建议 8/12 宽度）。
  - 右侧：课程信息与操作区（建议 4/12 宽度）。
- 平板/移动端（< 1024px）：纵向堆叠（播放器在上，信息在下）。
- 间距：页面外边距 24px（移动端 16px）；模块间距 16–24px。

### 3) Page Structure（结构）
1. 顶部导航条（可复用全站 Header）
2. 主内容区（Grid 两列）
   - 左列：播放器卡片 + 类型切换 + 播放状态/提示
   - 右列：课程信息卡片 + 当前资源信息
3. 全局提示层（Toast/Alert）

### 4) Sections & Components（组件与交互）

#### A. 顶部导航条 Header
- 左侧：产品/站点名称（可点击返回首页）。
- 中部（可选）：面包屑 “课程 / {课程标题}”。
- 右侧：用户区域（若已登录显示头像/昵称；若未登录则显示登录入口；仅作为占位，不在本需求强制实现）。

#### B. 播放器卡片 PlayerCard（核心）
- 容器：16:9 比例盒（aspect-ratio）+ 自适应宽度；背景纯黑/深灰。
- 顶部行：资源类型切换控件（Tabs/Segmented Control）。
  - Tab 值：视频 / 音频 / PDF / H5 / 外链（仅当课程详情返回存在对应资源时显示）。
- 主体内容：根据资源类型渲染：
  - 视频：HTML5 <video>（含 controls）；加载中显示 Skeleton。
  - 音频：HTML5 <audio> + 简洁封面占位区（可选）。
  - PDF：内嵌 PDF 预览（iframe/pdf viewer 容器），提供“新窗口打开”辅助链接。
  - H5：iframe 容器（默认禁止滚动；必要时允许）。
  - 外链：不直接 iframe 外站，展示外链引导卡片（见下）。
- 播放结束：
  - 结束瞬间弹出轻提示："已完成，正在上报进度…"；成功则提示"进度已记录"；失败提示"上报失败，点击重试"（按钮触发重试）。

#### C. 外链引导卡片 ExternalLinkCard
- 展示条件：当前资源类型为 external。
- 内容：
  - 标题：外部资源
  - 描述：提示“将跳转到第三方网站/平台完成学习”。
  - 链接信息：显示域名/URL（长链接截断，可复制）。
  - 主按钮：打开外链（target=_blank，noopener,noreferrer）。
  - 次按钮（可选）：复制链接。

#### D. 课程信息卡片 CourseInfoCard（右侧）
- 展示：课程标题（H1/H2）、课程简介（可折叠，默认 3 行截断）。
- 当前资源信息区：
  - 字段：资源标题（若有）、资源类型标签、资源状态（可用/不可用）。
- 异常态：
  - 详情接口失败：展示错误插画/图标 + “重试”按钮。
  - 空数据：展示“课程不存在或已下架”。

#### E. Loading / Error / Empty States
- Loading：播放器区域 Skeleton + 右侧信息骨架。
- Error：统一错误卡片（错误文案 + 重试）。
- Empty：统一空态卡片（返回上一页/返回首页）。

### 5) Responsive Behavior
- < 1024px：Tab 行固定在播放器卡片顶部；右侧信息卡片下移；按钮宽度自适应（主按钮可占满）。
- < 640px：标题字号下调一级；长 URL 强制换行或省略号截断。

### 6) Interaction & Motion
- Tab 切换：200ms 渐隐/渐显（仅容器过渡，不做复杂动画）。
- Toast：出现/消失 150–200ms。
- 播放器重建：切换类型时先卸载旧实例，避免同时播放与音频残留。
