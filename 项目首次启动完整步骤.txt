一、第一次打开项目
------------------

1. 启动 Docker Desktop，等待界面显示 Docker Engine 正常运行。

2. 启动 VS Code。

3. 点击“文件”→“打开文件夹”。

4. 选择：
   C:\Users\USER\Desktop\YY\language

5. 在 VS Code 中点击“终端”→“新建终端”。

6. 确认终端当前目录是：
   PS C:\Users\USER\Desktop\YY\language>

   如果不是，执行：

   cd C:\Users\USER\Desktop\YY\language


二、推荐启动方式：全部使用 Docker
----------------------------------

这是第一次使用和答辩演示最推荐的启动方式。

1. 在项目根目录执行：

   docker compose up --build -d

2. 等待镜像构建和三个服务启动。
   第一次构建可能需要几分钟，后续启动会更快。

3. 查看服务状态：

   docker compose ps

4. 正常情况下应看到：

   openedu-mysql      healthy
   openedu-backend    healthy
   openedu-frontend   healthy

5. 如果某个服务仍显示 starting，等待十几秒后再次执行：

   docker compose ps

6. 打开项目：

   http://localhost

7. 检查后端健康状态：

   http://localhost:3100/api/health

8. 检查后端和数据库是否就绪：

   http://localhost:3100/api/ready


三、Docker 分别启动 MySQL、后端和前端
-------------------------------------

如果希望观察每个服务的启动过程，可以按顺序执行。

1. 启动 MySQL：

   docker compose up -d mysql

2. 查看 MySQL 状态：

   docker compose ps

3. MySQL 显示 healthy 后，构建并启动后端：

   docker compose up --build -d backend

4. 后端显示 healthy 后，构建并启动前端：

   docker compose up --build -d frontend

5. 查看全部服务：

   docker compose ps

6. 查看后端日志：

   docker compose logs -f backend

   按 Ctrl+C 只会退出日志查看，不会停止容器。

7. 查看前端日志：

   docker compose logs -f frontend

8. 查看 MySQL 日志：

   docker compose logs -f mysql


四、本地开发方式：Docker 只运行 MySQL，前后端在 VS Code 中分别运行
----------------------------------------------------------------

该方式适合修改代码、观察热更新。

第一步：启动数据库
~~~~~~~~~~~~~~~~~~

在第一个 VS Code 终端中执行：

   cd C:\Users\USER\Desktop\YY\language
   docker compose up -d mysql
   docker compose ps

等待 openedu-mysql 显示 healthy。


第二步：配置并启动后端
~~~~~~~~~~~~~~~~~~~~~~

1. 在 VS Code 新建第二个终端。

2. 进入后端目录：

   cd C:\Users\USER\Desktop\YY\language\backend

3. 第一次运行时复制环境变量模板：

   Copy-Item .env.example .env

4. 打开 backend\.env，将数据库地址修改为：

   DATABASE_URL="mysql://root:root@localhost:3406/jiaoyu"

5. 确认以下配置存在：

   PORT=3000
   NODE_ENV="development"
   CORS_ORIGIN="http://localhost:5173"
   JWT_SECRET="change-me-to-a-strong-jwt-secret"
   ADMIN_JWT_SECRET="change-me-to-a-strong-admin-jwt-secret"
   ADMIN_BOOTSTRAP_EMAIL="admin@openedu.local"
   ADMIN_BOOTSTRAP_PASSWORD="change-me-admin-password"
   EDU_DATA_PROVIDER="mock"
   AI_ENABLED="false"

6. 安装后端依赖：

   npm ci

7. 生成 Prisma 客户端：

   npx prisma generate

8. 将数据库结构同步到 MySQL：

   npx prisma db push

9. 启动后端开发服务：

   npm run dev

10. 看到后端监听 3000 端口后，不要关闭该终端。

11. 在浏览器检查：

   http://localhost:3000/api/health
   http://localhost:3000/api/ready


第三步：启动前端
~~~~~~~~~~~~~~~~

1. 在 VS Code 新建第三个终端。

2. 进入前端目录：

   cd C:\Users\USER\Desktop\YY\language\frontend

3. 第一次运行时安装依赖：

   npm ci

4. 启动前端开发服务：

   npm run dev

5. 保持终端运行，打开：

   http://localhost:5173

6. Vite 会把 /api 请求自动转发到：

   http://localhost:3000

六、停止项目
------------

停止 Docker 服务但保留数据库数据：

   cd C:\Users\USER\Desktop\YY\language
   docker compose down

只停止服务、不删除容器：

   docker compose stop

再次启动已存在的容器：

   docker compose start

本地开发模式下：
- 在前端终端按 Ctrl+C。
- 在后端终端按 Ctrl+C。
- 数据库可以继续运行，也可以执行：

   docker compose stop mysql

不要执行下面的命令，除非明确希望删除全部本地数据库数据：

   docker compose down -v

九、常见问题
------------

1. docker 命令提示找不到 Docker Engine

   先启动 Docker Desktop，等待 Docker Engine 完成启动，再执行：

   docker compose ps

2. 80 端口被占用

   检查占用：

   Get-NetTCPConnection -LocalPort 80 -ErrorAction SilentlyContinue

   本地开发时可以直接使用：

   http://localhost:5173

3. 后端无法连接数据库

   Docker 全部运行时，DATABASE_URL 中主机名应为 mysql，端口为 3306。

   VS Code 本地运行后端时，DATABASE_URL 应为：

   mysql://root:root@localhost:3406/jiaoyu

4. 前端页面可以打开，但接口请求失败

   Docker 模式检查：

   http://localhost:3100/api/ready

   本地开发模式检查：

   http://localhost:3000/api/ready

5. 修改代码后 Docker 页面没有变化

   重新构建对应服务：

   docker compose up --build -d backend
   docker compose up --build -d frontend
