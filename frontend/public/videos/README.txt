课程视频放置目录
================

把视频文件放入对应语种目录：

en = 英语        ru = 俄语        fr = 法语
ja = 日语        de = 德语        es = 西班牙语
ko = 韩语

示例：
  电脑文件：frontend/public/videos/en/a1-greetings-01.mp4
  后台来源：/videos/en/a1-greetings-01.mp4

文件要求：
1. 推荐 MP4（H.264 视频 + AAC 音频），也支持浏览器可播放的 WebM。
2. 文件名只用小写英文字母、数字和短横线，不用空格或中文。
3. 推荐 720p、16:9；单段 3-8 分钟、20-80 MB。
4. 不要在后台填写 C:\ 开头的电脑路径。
5. 每个外部素材都要在项目根目录“视频资源来源登记模板.txt”登记来源和授权。

Docker 模式已经把本目录只读挂载到网站中。首次应用配置时运行：
  docker compose up -d --build frontend

以后复制新视频到本目录后，通常只需刷新浏览器，不必重新构建前端。
