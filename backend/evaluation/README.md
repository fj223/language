# 智能问答评测说明

## 当前基准

`intent-evaluation.v1.json` 包含：

- 196 条单轮问题：7 类意图，每类 28 条。
- 14 条多轮上下文问题。
- 中文、英文和俄文表达。
- 直接提问、口语化表达、隐式表达、比较、否定和安全边界等标签。

运行：

```bash
npm run evaluate:chatbot
```

输出：

```text
evaluation/results/intent-evaluation-v1.json
```

报告包含关键词基线、OpenEdu 意图分类器和上下文解析器的 Accuracy、Macro Precision、Macro Recall、Macro-F1、分类明细、混淆矩阵、失败样例、平均延迟和 P95 延迟。

## 使用边界

该数据集已经用于工程回归和规则改进，因此只能作为“版本化回归基准”，不能直接作为论文最终的独立测试集。

论文正式实验还需要：

1. 冻结当前分类器和规则版本。
2. 由未参与规则开发的人员重新收集或改写问题。
3. 至少两名标注者独立标注意图，并报告一致性。
4. 保留无法达成一致的样例和裁决过程。
5. 在独立测试集上只运行一次最终评测，不继续针对测试集修改规则。
6. 将回归基准和独立测试结果分别报告，避免数据泄漏。

建议最终独立测试集不少于 210 条，并保持每个意图、语言和难度层级的数量相对均衡。

## 指标解释

- Accuracy：全部问题中意图预测正确的比例。
- Macro-F1：先计算每个意图的 F1，再等权平均，避免样本多的类别掩盖弱类别。
- Context Accuracy：当前问题依赖历史对话时，正确继承或转换意图的比例。
- P95 Latency：95% 的分类请求可在该时间内完成。

意图正确不等于回答事实正确。论文还需要单独评估：

- 课程、课表和成绩事实正确率。
- 政策检索 Recall@K 和 MRR。
- 数据来源标注正确率。
- 未登录个人查询和高风险操作的安全拒答率。
- 多轮任务最终完成率。
